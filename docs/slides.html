① 병목을 짐작했다. 데이터 준비가 느린 줄 알고 일꾼을 늘렸더니 더 느려졌다. 재 보니 GPU 가 병목이었다 (85초 vs 20초).
② 판정을 부등호로 했다. 40장짜리 두 평균을 크다/작다로 비교했더니, 같은 데이터로 학습한 두 모델이 정반대 판정을 냈다. 신뢰구간으로 바꾸자 세 모델이 일관되게 "판정보류"로 모였다.
③ 항상 통과하는 검사를 만들었다. 어떤 기준을 세웠더니 여덟 클래스가 전부 통과했다. 통과하지 못하는 경우가 없는 검사는 검사가 아니다. 기준을 갈아엎었다.

셋의 원인은 같다. 짐작을 결과로 적으면 안 되고, 아무나 통과하는 검사는 검사가 아니다.
