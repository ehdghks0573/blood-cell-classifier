## 1. 프로젝트 정의

### 한 줄 정의

현미경 혈액 도말 이미지를 8종의 백혈구로 분류하고, **모델이 이미지의 어디를 보고
그렇게 판단했는지** Grad-CAM 히트맵으로 보여준다.

### 왜 이 주제인가

분류 정확도만 높이는 프로젝트는 "숫자 하나"로 끝난다. 여기에 설명가능성을 붙이면
**모델이 틀렸을 때 왜 틀렸는지**를 눈으로 보여줄 수 있고, 그게 의료 AI 에서 가장
중요한 질문이다. 8클래스라 혼동행렬이 의미 있게 나오는 것도 이 데이터셋을 고른
이유다 — 2진분류였다면 "정확도 95%" 한 줄로 끝났을 것이다.

### 데이터

**BloodMNIST** (MedMNIST v2). 현미경 혈액 도말 이미지 17,092장, 8클래스.

| 라벨 | 세포 |
| ---: | --- |
| 0 | basophil (호염기구) |
| 1 | eosinophil (호산구) |
| 2 | erythroblast (적아구) |
| 3 | immature granulocytes (미성숙 과립구) |
| 4 | lymphocyte (림프구) |
| 5 | monocyte (단핵구) |
| 6 | neutrophil (호중구) |
| 7 | platelet (혈소판) |

인증 없이 자동으로 내려받는다. 64px(빠른 실험용)과 224px(최종 학습용)을 모두 받아
둔다. 코드를 고칠 때마다 224px 로 돌리면 한 번에 몇 분씩 날아간다.

### 성공 기준

| # | 항목 | 기준 | 측정 방법 |
| --- | --- | --- | --- |
| S1 | 분류 성능 | test **macro F1 ≥ 0.96** | `train.py` 최종 출력 |
| S2 | 클래스별 성능 | 어떤 클래스도 F1 < 0.90 이 없을 것 | 분류 리포트 |
| S3 | 재현성 | 같은 시드로 두 번 돌려 macro F1 차이 < 0.01 | 두 번 실행 비교 |
| S4 | 설명가능성 | 8클래스 전부 Grad-CAM 히트맵 생성 | `explain.py` |
| S5 | 오류 분석 | 혼동 상위 3쌍에 대해 원인 서술 | `docs/results.md` |
| S6 | 학습 시간 | 1회 학습 30분 이내 | 로그 |

**정확도(accuracy)가 아니라 macro F1 을 기준으로 삼는다.** 클래스가 불균형하면
정확도는 다수 클래스만 맞혀도 높게 나와서, 성능을 잘못 읽게 만든다.

> **기준을 한 번 올렸다.** 처음에는 S1 을 0.90, S2 를 0.80 으로 잡았는데,
> 3 에폭짜리 검증 학습에서 이미 macro F1 0.9601, 최저 클래스 0.9117 이 나왔다.
> 넘기 쉬운 기준을 두고 "달성했다"고 쓰는 것은 의미가 없으므로 실측 베이스라인에
> 맞춰 올렸다. **기준을 언제 왜 바꿨는지 남기는 것까지가 정직한 실험 기록이다.**
>
> 동시에 이 수치는 **성능 튜닝에 시간을 더 쓸 이유가 적다**는 뜻이기도 하다.
> macro F1 을 0.96 에서 0.97 로 올리는 것은 발표에서 아무도 신경 쓰지 않는다.
> 남는 시간은 Grad-CAM 과 오류 분석(Day 8~10)에 쓴다.

### 범위

**포함** — 데이터 로딩·증강, 전이학습 분류기, 학습/평가 파이프라인, 혼동행렬,
클래스별 지표, Grad-CAM, 오류 분석, 실험 비교표

**제외** — 세그멘테이션, 객체 검출, 모델 직접 설계(전이학습만), 웹 서비스 배포,
여러 데이터셋 동시 지원

### A. 실험 기록 규칙

### B. 자주 겪는 문제

| 증상 | 원인 | 해결 |
| --- | --- | --- |
| CUDA out of memory | 배치가 큼 | 배치를 16으로, 또는 해상도를 낮춘다 |
| 학습 손실이 안 내려감 | 학습률이 큼 | 1e-3 → 1e-4 |
| train 은 좋은데 val 이 나쁨 | 과적합 | 증강 강화, 조기 종료 |
| 특정 클래스만 F1 이 낮음 | 데이터 부족 | 클래스 가중치 |
| 결과가 매번 다름 | 시드 미고정 | torch/numpy/random 시드 고정 |
| 학습이 너무 느림 | DataLoader 병목 | `num_workers` 조정 |

### C. 진행 체크리스트
