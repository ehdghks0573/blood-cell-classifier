## 3. 학습 시간 — 해상도를 낮춰 해결했다 (S6)

어제 `tools/bench.py` 로 병목이 **GPU** 임을 확인했다(에폭당 GPU 85초 vs 데이터
로딩 20초). 데이터 로딩을 아무리 최적화해도 소용없고, GPU 연산량 자체를 줄여야
한다는 뜻이었다. 원본이 28px 인데 224px 로 늘려 넣고 있었으므로 112px 로 낮췄다.

| 입력 | test macro F1 | 학습 시간 | 최저 클래스 F1 |
| ---: | ---: | ---: | ---: |
| 224px | 0.978057 | 33.4분 | 0.9494 (monocyte) |
| 112px | 0.974868 | **11.9분** | 0.9405 (IG) |
| 차이 | **−0.003189** | **2.8배 빠름** | |

**성능을 조금 잃었고, 그 "조금"이 얼마인지 잴 수 있게 됐다.** 아래 S3 측정으로
시드에 의한 흔들림이 0.000155 임을 알았으므로, 0.003189 는 **그 20배**다.
우연이 아니라 해상도를 낮춘 실제 대가다.

**그래도 112px 를 작업 기준으로 삼는다.** S1·S2 를 모두 통과하고, 실험 한 번이
33분에서 12분으로 줄어든다. 남은 기간에 실험을 여러 번 돌릴 수 있는 쪽이,
macro F1 0.003 보다 프로젝트에 이롭다. 최종 보고에는 두 숫자를 모두 싣는다.

## 4. 재현성 (S3)

같은 명령을 두 번 실행했다 (`res112_resnet18`, `res112_rerun_seed42`).

```
1회차 macro F1  0.974868057672553
2회차 macro F1  0.974868057672553
차이            0.0000000000
혼동행렬 동일?  True
학습곡선 동일?  True      ← 20 에폭의 손실·지표가 전부 일치
```

기준(< 0.01)을 통과한 정도가 아니라 **완전히 같다.** `src/seeding.py` 가
`cudnn.deterministic` 까지 고정하기 때문이다.

### 그러나 "같은 시드"의 범위는 좁다

| 무엇을 바꿨나 | macro F1 차이 |
| --- | ---: |
| 아무것도 (같은 명령 두 번) | **0.0000000** |
| 시드 42 → 43 | 0.000155 |
| **`--num-workers` 2 → 4** (시드는 그대로 42) | **0.0083** |
| 입력 224px → 112px | 0.003189 |

`--num-workers` 를 바꾼 것만으로 시드가 같은데도 0.0083 이 어긋난다. 워커 수가
바뀌면 증강에 쓰이는 난수 흐름 자체가 달라지기 때문이다(`docs/experiments.md`).

**시드 고정은 "명령줄이 한 글자도 다르지 않을 때"만 재현을 보장한다.** 그리고
그 흔들림(0.0083)이 해상도를 절반으로 줄인 대가(0.0032)보다 크다는 점이 중요하다.
실험을 비교할 때 인자를 두 개 이상 바꾸면 무엇이 효과였는지 알 수 없다.

## 5. 오류 분석 — 가설을 검증했고, 절반만 살아남았다 (S5)

어제 세운 가설: 남은 오분류가 **neutrophil · immature granulocytes · monocyte**
세 클래스(이하 삼각지대) 안에만 갇혀 있는 이유는 모델의 결함이 아니라 **라벨이
연속선상에 있어 모호하기 때문**이다.

가설을 그냥 두면 이야기일 뿐이므로, **틀렸다면 어떤 숫자가 나와야 하는지**를
먼저 정하고 `analyze.py` 로 쟀다.

| | 예측 | 결과 (3개 모델) |
| --- | --- | --- |
| P1 | 삼각지대 오류에서 덜 확신한다 | **판정보류** |
| P2 | 정답이 2순위에 남는다 | **판정보류** (3개 중 1개만 맞음) |
| P3 | 마진(p_예측 − p_정답)이 작다 | **판정보류** |
| P4 | 2순위에 실린 확률이 크다 | **맞음** (3개 모두) |

### P1~P3 이 판정보류인 이유 — 표본이 없다

오분류가 test 3,421장 중 **70~83장**뿐이고, 그중 삼각지대는 40~50장이다.

```
삼각지대 0.818 vs 그 밖 0.768 · 차이 +0.050 (95% 구간 −0.035 ~ +0.136)
```

95% 구간이 0 을 걸친다. **"차이가 없다"가 아니라 "이 표본으로는 말할 수 없다"**
이다. 모델이 잘 맞힐수록 오류 분석의 표본이 줄어드는, 피할 수 없는 긴장이다.

> **판정 코드를 두 번 갈아엎었다.** 처음에는 두 평균을 부등호로만 비교했는데,
> 같은 데이터로 학습한 두 모델이 **정반대 판정(3개 중 1개 / 3개 모두)** 을
> 냈다. 40장짜리 평균은 그 정도로 흔들린다. 부트스트랩 신뢰구간으로 바꾸자
> 세 모델이 일관되게 "판정보류"로 모였다. **판정이 표본에 따라 뒤집히면 그건
> 결과가 아니라 도구의 결함이다.**

### P4 — 표본을 100배로 늘려 얻은 유일한 신호

오분류 40장 대신 **맞힌 3,300장**을 봤다. 라벨이 연속선상에 있다면 그 이웃
관계는 틀린 장에서만 나타날 리 없고, 맞힌 장의 2순위에도 드러나야 한다.

| 모델 | 삼각지대 | 그 밖 | 차이 (95% 구간) |
| --- | ---: | ---: | --- |
| 224px seed 42 | 0.0163 | 0.0056 | **+0.011** (+0.007 ~ +0.014) |
| 112px seed 42 | 0.0156 | 0.0059 | **+0.010** (+0.007 ~ +0.013) |
| 112px seed 43 | 0.0172 | 0.0056 | **+0.012** (+0.008 ~ +0.015) |

**세 모델에서 거의 같은 값으로 재현된다.** 삼각지대 클래스는 2순위에 약 3배의
확률을 싣는다 — 이웃 클래스가 실질적으로 경쟁하고 있다는 뜻이다.

> **여기서도 기준을 한 번 갈아엎었다.** 처음에는 "2순위가 이웃 클래스인가"를
> 우연(1/7 = 14.3%)과 비교했고 **여덟 클래스가 전부 통과했다.** platelet 은
> 2순위가 96.6% 확률로 erythroblast 인데 실제로는 **한 장도 안 틀린다** —
> 2순위에 실린 확률이 0.0019 에 불과한 잔여물이기 때문이다. 어느 클래스가
> 2순위인지는 모든 클래스에서 쏠려 나오므로 구분에 쓸 수 없다.
> **항상 통과하는 검사는 검사가 아니다.**

### P4 를 클래스별로 뜯어보면 — 삼각지대라는 이름이 헐겁다

| 클래스 | 2순위 | 2순위 확률 (224px) | (112px) |
| --- | --- | ---: | ---: |
| △ immature granulocytes | neutrophil | 0.0243 | 0.0245 |
| △ monocyte | immature granulocytes | 0.0243 | 0.0191 |
| basophil | immature granulocytes | **0.0145** | **0.0284** |
| erythroblast | platelet | 0.0115 | 0.0031 |
| lymphocyte | — | 0.0061 | 0.0090 |
| △ **neutrophil** | immature granulocytes | **0.0062** | **0.0067** |
| eosinophil | — | 0.0018 | 0.0019 |
| platelet | erythroblast | 0.0019 | 0.0002 |

**두 가지가 가설과 어긋난다.**

1. **neutrophil 은 낮다** (0.0062). 삼각지대의 한 축인데도 삼각지대 밖 클래스와
   비슷하다. 666장으로 가장 많고 형태가 뚜렷해서, 모델이 이 클래스만큼은
   자신 있게 분리한다.
2. **basophil 은 높다** (0.0145 / 0.0284). 삼각지대 밖인데 IG 를 2순위로 두고
   상당한 확률을 싣는다.

따라서 P4 가 실제로 말하는 것은 "세 클래스가 서로 경쟁한다"가 아니라
**"immature granulocytes 가 여러 클래스와 경쟁한다"** 에 가깝다. IG 는
monocyte·basophil·neutrophil 모두의 2순위로 등장한다.

이는 미성숙 과립구가 **성숙 단계의 중간 지점**이라는 설명과 맞아떨어진다.
연속선의 한쪽 끝(neutrophil)은 뚜렷하고, 중간(IG)이 여러 방향으로 번진다.

### 정리 — 가설은 좁혀졌다

- **살아남은 것** — IG 를 중심으로 클래스들이 실질적으로 경쟁한다는 것은
  세 모델에서 재현되는 사실이다.
- **살아남지 못한 것** — "세 클래스가 대칭적인 삼각형을 이룬다"는 그림은 틀렸다.
  neutrophil 은 그 축에 끼지 않는다.
- **아직 못 밝힌 것** — 이 경쟁이 **라벨의 모호성** 때문인지 **모델의 한계**
  때문인지는 확률 분포만으로 가릴 수 없다. 40장짜리 표본으로 P1~P3 을 재려던
  시도가 실패한 것이 그 증거다.

**다음은 눈으로 보는 검증이다.** 확신에 차서 틀린 IG 관련 오분류를 모아 사람이
직접 보는 것 외에 남은 방법이 없다 (`docs/PLAN.md` Day 10).

### Grad-CAM 관찰 (224px 모델)

최종 모델은 **틀린 경우에도 거의 전부 세포(주로 핵)에 히트맵이 집중**된다.
에폭 3 짜리 모델에서는 히트맵이 배경과 이미지 가장자리로 번져 있었다. 학습이
진행되면서 모델이 "어디를 봐야 하는지"를 먼저 배웠고, 남은 오류는 보는 위치의
문제가 아니게 됐다. 남은 오분류가 엉뚱한 단서 때문이 아니라는 근거다.

## 7. 한계

- **28px 저해상도.** 원본 데이터의 224px 버전을 확보하지 못했다. 지금의 "224px
  입력"은 28px 를 늘린 것이라, 진짜 고해상도 데이터로는 결과가 다를 수 있다.
- **P1~P3 을 측정하지 못했다.** 오분류가 70~83장뿐이라 표본이 부족하다.
  이 데이터셋에서 더 큰 표본을 얻으려면 일부러 나쁜 모델을 쓰는 수밖에 없는데,
  그건 다른 모델의 오류를 재는 것이라 답이 되지 않는다.
- **모호성인지 모델 한계인지 아직 못 가렸다.** 확률 분포로는 여기까지가 끝이다.
- **단일 데이터셋.** 다른 병원·장비·염색 조건은 보장할 수 없다.
- **임상 사용 불가.** 임상 검증을 거치지 않았고, 그럴 목적으로 만들지 않았다.
